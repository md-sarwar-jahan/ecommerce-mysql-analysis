# Ecommerce MySQL Analysis Project

This project uses MySQL to analyze ecommerce sales data. It includes data quality checks, business KPIs, customer insights, and sales target analysis.

## Files
- `list_of_orders.csv`: Contains order details like customer names and dates.
- `order_details.csv`: Contains order items, amounts, and profits.
- `sales_target.csv`: Contains monthly sales targets by category.
- `ecommerce_analysis.sql`: MySQL script with all queries for creating the database, cleaning data, and analyzing it.

## How to Run
1. Import the CSV files into MySQL using a tool like MySQL Workbench or phpMyAdmin.
2. Run the `ecommerce_analysis.sql` script to set up the database and see the analysis.

## What This Project Shows
- **Data Quality**: Checks for duplicates, missing data, and negative amounts.
- **Business KPIs**: Calculates total revenue, profit, and average order value.
- **Customer Insights**: Finds repeat customers and top cities for sales.
- **Sales Targets**: Compares actual sales to targets.
- **Retention**: Analyzes customer purchases over time.
